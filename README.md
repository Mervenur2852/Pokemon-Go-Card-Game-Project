# 🎴⚡  Pokemon-Go-Card-Game-Project
A fun and interactive Pokémon Card Game developed with React!  This project lists cards, each representing a different Pokémon, and allows players to collect experience points. At the end of the game, players are ranked, and the one with the highest score wins!

 # 🚀 Features
Pokémon Cards: Each card displays the Pokémon's name, type, and experience points. 
Winner & Loser: The winner is determined based on the total experience points of the players! 🥇
Interactive Effects: When hovering over the cards, a dynamic glow and zoom effect create a visually stunning experience! 🌟🔍

# 🛠️ Kullanılan Teknolojiler
ReactJS – For dynamic interfaces and powerful state management ⚛️
CSS – To create modern and stylish designs 🎨
Google Fonts – To add unique and aesthetic typography 🔠
CSS Gradients – To enhance visuals with smooth color transitions 🌈
PokéAPI – To access real-time Pokémon data 🐉
